# Code of conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/), in every project space: issues, pull requests, discussions, and any channel where someone represents the project.

In short: be respectful, argue about classes with evidence rather than about people, and assume good faith. Harassment, personal attacks, and publishing someone's private information are not acceptable.

## Reporting

Report conduct problems privately through the repository's [private reporting form](https://github.com/TwoMuchLabs/reversibility-classes/security/advisories/new), starting the title with **"Conduct report:"**. Only the maintainers can read it. If the report concerns a maintainer, say so, and it will be handled by someone not involved.

Reports are handled confidentially. Responses follow the Covenant's [enforcement guidelines](https://www.contributor-covenant.org/version/2/1/code_of_conduct/#enforcement-guidelines): correction, warning, temporary ban, or permanent ban, depending on the impact.
